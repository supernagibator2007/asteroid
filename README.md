## Описание проекта

Программа представляет собой игру про корабль, который должен уничтожать астероиды. 
Игровое поле имеет тороидальную геометрию, корабль может вращаться, ускоряться и стрелять.
У игрока есть 3 жизни, после чего игра заканчивается.

## Функциональные возможности

### Основной функционал
- Управление космическим кораблём с инерцией, ускорением и поворотом
- Стрельба снарядами с временем перезарядки
- Генерация астероидов
- Уничтожение астероида при попадании снаряда и начисление +1 очка
- Система из 3 жизней
- Непрерывный игровой процесс с автоматическим поддержанием количества астероидов на поле

### Дополнительный функционал
- Режим паузы во время игры
- Процедурно сгенерированное звёздное небо на заднем плане

## Требования к системе

- **Python:** 3.13 или ниже (рекомендуется не ниже 3.9)
- **Операционная система:** Windows / macOS / Linux

### Для анимации
- `pygame` (2.6.1)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/supernagibator2007/asteroid.git
cd asteroid
```

### 2. Виртуальное окружение

#### Виртуальное окружение на Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Виртуальное окружение на Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск

#### Запуск на Windows

```bash
python main.py
```

#### Запуск на Linux/macOS

```bash
python3 main.py
```

## Управление

| Клавиша | Действие |
| :--- | :--- |
| `W` / `↑` | Включить тягу двигателя (ускорение вперёд) |
| `A` / `←` | Поворот корабля против часовой стрелки |
| `D` / `→` | Поворот корабля по часовой стрелке |
| `Space` | Выстрел |
| `P` | Пауза / продолжить игру |
| `Enter` / `R` | Начать игру / перезапустить после проигрыша |
| `Esc` | Выход из программы |

## Структура проекта

```text
asteroid_game/
├── .gitignore

    ├── __init__.py

    │   ├── entities.py
    │   └── game_model.py
    ├── renderers/
    │   ├── __init__.py
    │   └── game_renderer.py
    └── widgets/
        └── __init__.py
```

**Назначение основных модулей:**
- `main.py` — точка входа в программу, создание и запуск главного приложения.
- `src/app.py` — класс `AsteroidApp`: инициализация окна Pygame, обработка событий клавиатуры и главный игровой цикл с фиксированным FPS.
- `src/models/entities.py` — классы игровых сущностей (`Ship`, `Asteroid`, `Bullet`), их физика перемещения, вращения и обёртки координат за границы экрана.
- `src/models/game_model.py` — класс `GameModel` и перечисление `GameState`: игровая логика, спавн астероидов, проверка столкновений окружностей, подсчёт очков и управление жизнями.
- `src/renderers/game_renderer.py` — класс `GameRenderer`: отрисовка звёздного фона, корабля, астероидов, интерфейса (HUD) и информационных оверлеев.
